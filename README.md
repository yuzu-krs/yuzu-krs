## Projects

### [Proxlane](https://proxlane.com)

Developer-focused tunneling platform for exposing local services to the Internet.

Supports **HTTP, HTTPS, TCP, and UDP** tunneling with features including reserved hostnames, fixed endpoints, endpoint protection, traffic inspection, logging, billing, CLI tooling, Desktop Launcher, and MCP integration.

### [cloudru.jp](https://cloudru.jp)

Cloud server platform for development environments, game servers, and self-hosted applications.

Built with technologies including **SQLite** and **Stripe**.

### [DropJet](https://dropjet.proxlane.com)

Simple temporary file sharing service focused on fast uploads and straightforward sharing.

### [Board Game](https://boardgame.proxlane.com)

Browser-based board game application running on the Proxlane ecosystem.

### Minecraft Projects

**[YuzuClient](https://github.com/yuzu-krs/YuzuClient)**  
Minecraft client development and experimentation.

**[EduCraft](https://github.com/yuzu-krs/EduCraft)**
